# Narrow Detail Overlay uses full-bleed scrolling, a three-tier header, and a Detail Bottom Bar

On viewports at or below 1024px, Detail Overlays suffered from three compounding layout defects: inner scroll areas sat inside outer pane padding without scrollbar clearance so the vertical thumb collided with content; subject headers mixed repository identity, status pills, timestamps, and pull-request branch refs into wrapping rows while spending leading horizontal space on a duplicate title icon; and the Detail Sidebar toggle lived in an awkward inner slot of the Top Bar using a desktop right-column icon, hiding high-frequency actions such as opening the PR Review Workspace or downloading release assets inside a collapsed sheet.

At and below 1024px, Detail Overlays now let the active scrollport span the full viewport width with the page Gutter inside its scrolled content so the scrollbar track sits flush on the right edge with consistent separation. Pull request, issue, discussion, and release headers adopt a unified three-tier hierarchy across all viewports (eyebrow above the title, full-width title without a duplicate leading icon, and a single-line status strip), with pull requests adding a dedicated single-line `head → base` branch row that expands on tap and copies the source branch in one tap. On narrow viewports, the Top Bar drops the Detail Sidebar toggle and a persistent Detail Bottom Bar hosts primary actions (the top-level Conversation Composer sheet, PR Review Workspace launch with diff totals, and the Detail Sidebar sheet), while both narrow sheets escape SimpleBar's inner mask stacking context via a dedicated stage layer that provides a scrim, downward swipe dismissal, and Escape handling.

Rejected alternatives: promoting primary actions only into the top of the page (lost once the reader scrolls down a long conversation); turning metadata and actions into top-level page tabs (forces losing scroll position when acting at the bottom of a thread); adding a second sticky top toolbar (spends vertical reading space outside thumb reach); and keeping the narrow top-level Conversation Composer as an inline sticky capsule (redundant with the Detail Bottom Bar and unreachable from non-conversation tabs).

**Consequences**: 1024px remains the single narrow switch shared by Detail Overlays and the PR Review Workspace (ADR 0008). Top-level Conversation Composers open in a bottom sheet on narrow viewports, keeping drafts when dismissed via scrim, Escape, or swipe and clearing only on explicit Cancel or submission, while inline discussion reply editors remain under their parent comment and suppress the Detail Bottom Bar while open.
